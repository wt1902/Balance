# Проверки переноса

Дата: 28 октября 2026. SDK Flutter 3.47.8 / Dart 3.13.7, Linux x64.

## Подтверждено

- Финансовые модели и расчёты: 13 unit-тестов, включая исключение корректировок, границы месяца, CSV, точное локальное хранение целых сотых и локальный месяц бюджета после серверного UTC round trip. Проверка часового пояса также запускалась с `TZ=Europe/Moscow`.
- Хранилище: 10 тестов — восстановление, dirty/tombstone, каскады, rollback курсора, scoped accounts, headless store, два экземпляра store, logout и ротация токенов между engines.
- HTTP-протокол: 7 MockClient-тестов — auth, пакетная отправка, страницы, ошибки и валидация.
- RuntimeLock: 3 Dart channel-теста. Web origin-wide Web Locks проверены компиляцией JavaScript и Node 24 native navigator.locks (владение, ожидание, освобождение, повторное получение и отказ без secure context/API). Android Java release compilation и 3 JVM-теста: сериализация потоков, повторное освобождение, прерывание ожидания, реальное межпроцессное состязание за file lock.
- Интерфейс: 22 widget/screenshot-теста. Все пять экранов с пустой и заполненной базой на 320×568, 390×844 и 1280×900, формы и ошибки ввода, CRUD операций/категорий/бюджетов, текст 1.5×, тёмная тема, отрицательная корректировка, CSV через save selector и share sheet с проверкой байтов.
- Настоящий Go HTTP-сервер: регистрация, вход, `/me`, 1102 записи, страницы `[500,500,102]`, изменения, удаление, replay старой записи, изоляция двух пользователей, refresh rotation и отзыв refresh после logout. Запуск: `bash tool/run_integration.sh` (нужны Go 1.25+ и Dart).
- Общий финальный запуск: **55 Flutter-тестов прошли**, `flutter analyze` — **No issues found**.
- Web JavaScript release с локальным CanvasKit и Linux x64 release собраны. Android universal release APK также собран и снабжён отдельной тестовой подписью; проверяются apksigner и 16 KiB zipalign. WorkManager Kotlin/AGP compatibility настроена в runner Gradle.
- Go-сервер не изменялся; cloud-capabilities удалены из Apple templates, SwiftData явно локальный.

В исходном checkout отсутствует `BalanceServer/cmd/balance-server`, хотя README и Dockerfile на него ссылаются (каталог исключается исходным ignore pattern). Поэтому integration runner создаёт временный `main` **только во временной копии**, вызывая исходные config/database/httpapi; исходный сервер остаётся без изменений. Это ограничение исходного репозитория, а не изменение протокола или сервера в переносе. Для обычной серверной Docker-сборки нужен оригинальный entry point; уже работающий Go-сервер можно использовать напрямую.

## Что ещё требует целевой среды

- iOS/iPadOS, macOS, Windows и watchOS не собирались в этой Linux-среде. Runners и CI созданы; реальные результаты CI не получены.
- watchOS — сохранённый нативный SwiftUI target, не Flutter. Material 3 относится к Flutter-клиенту.
- Полная проверка WorkManager после закрытия/остановки приложения, system Keychain/Keystore, iPad share popover, файловых диалогов, доступности и реальной клавиатуры требует устройств.
- Linux release слинкован, но запуск GTK под Xvfb/DBus был заблокирован ограничением сокетов среды. Локальные финансы и запуск store проверены unit/widget-тестами; реальный Secret Service пользователя здесь не проверен.
- Web runtime в настоящем браузере, CORS с пользовательским сервером, PWA install/offline reload и обновление кэша здесь не проверялись.
- Подпись Apple, публикация и магазины не выполнялись. Android тестовая подпись, если приложена, предназначена для проверки установки.
- Перенос старой SwiftData/Room базы выполняется через существующий сервер; прямого чтения чужого sandbox нет. Старое приложение следует сохранить до сверки данных.

## Принятые различия

Material 3 и адаптивная навигация; денежные значения в целых сотых (старые доли менее сотой округляются); границы периодов `[start,end)`; отдельные данные аккаунтов; график динамики — пары столбцов. CloudKit удалён по прямому запросу. Финансовые payload, UUID, даты обновления, корректировки, категории, бюджеты и удаления совместимы с исходным сервером.

## Обновление 4.1 — режимы и пресеты

Добавлены Лес, Индиго, Океан, Роза и OLED. Режим (system/light/dark) и пресет сохраняются независимо в локальных настройках. При выборе OLED сначала включается dark; затем разрешено выбрать system. В тёмном OLED все основные Material surfaces, карточки, app bar, навигация и диалоги используют `#000000`, overlay tint отключён.

Общий запуск после изменений: 62 Flutter-теста PASS; анализатор No issues found. Новые проверки: точные цвета OLED, разные акценты пресетов, сохранение/перезапуск, реакция системного режима на OS brightness, выбор на экране 320px и проверка чёрных пикселей снимков 390/1280px.

APK 4.1 использует новый тестовый ключ, поскольку временный ключ предыдущей тестовой сборки не сохранился после смены среды. Прямая установка поверх APK 4.0 с другой подписью невозможна. Перед заменой старой тестовой сборки синхронизируйте её с Go-сервером и убедитесь в сохранности данных. Для последующих сборок ключ 4.1 сохранён отдельно от репозитория и исходного архива. Для публикации нужен собственный release keystore.

## Обновление 4.2 — данные и надёжность

Проверено: `test/statement_import_test.dart` (12 тестов) — определение разделителя и кодировок (UTF-8, BOM, UTF-16 LE/BE с BOM, Windows-1251), Т-Банк по заголовку, сопоставление колонок, OFX 1.x/2.x, точный разбор сумм до сотых, стабильные id и отсутствие дублей при повторном импорте. `test/data_tools_test.dart` (7 тестов) — бэкап без потерь, восстановление по last-write-wins (новые локальные записи и удаления побеждают), пропуск дублей категорий и бюджетов, отказ от новой версии формата, карантин повреждённых локальных записей и записей с сервера, продолжение запуска и коммит страницы pull.

`test/data_tools_ui_test.dart` (15 тестов: 5 сценариев на 320×568, 390×844 и 1280×900) — диалог сопоставления колонок CSV, предпросмотр импорта (возможный дубль снят, уже импортированная строка заблокирована, смена категории, итоговый список операций), панель отложенных записей, предпросмотр восстановления из копии (статусы, причины пропуска, выборочное восстановление) и импорт собственного CSV (ID, корректировки и оформление сохраняются, категорию корректировки сменить нельзя). Переполнений и исключений нет.

Общий запуск: 99 Flutter-тестов PASS (новые наборы также с `TZ=Europe/Moscow`), анализатор No issues found. В Web-сборке вручную проверены раздел «Данные» на 375 и 1280 px и кнопка «Резервная копия»: файл `balance-backup-<дата>.json` скачивается и содержит корректный конверт (`format`, `version`, `exportedAt`, `data`). Системные диалоги проверены вручную на реальных сборках 4.2.0 с тестовыми файлами (копия JSON, CSV Т-Банка в Windows-1251, OFX 1.x):

- **Linux (release, GTK `GtkFileChooserNative` без портала, изолированные Xvfb и D-Bus):** открытие с фильтрами «Резервная копия» и «Выписка», сохранение копии с предложенным именем `balance-backup-<дата>.json`. Восстановление дало «добавлено 4», импорт CSV — 3 операции, отклонённая пропущена. Повторный импорт показал «уже импортирована» для всех строк, OFX — 2 операции. Сохранённая копия содержала 5 операций, 1 категорию и 1 бюджет.
- **Android 15 (эмулятор API 35, release x86_64):** системный выбор файлов (DocumentsUI) для восстановления и импорта CSV и OFX, окно «Поделиться» с файлом `balance-backup-<дата>.json` для копии. Итоговый баланс 176 479,50 ₽ совпал с расчётом. Найдено и исправлено: Android фильтрует только по MIME-типу, а `.ofx` хранится как `application/octet-stream`, поэтому выписка не была видна. Для Android добавлены OFX-типы и `application/octet-stream`.
- **Ограничение Android:** копия и CSV сохраняются через «Поделиться» (Drive, почта, мессенджеры), отдельного «Сохранить на устройство» нет, так же работал и прежний экспорт CSV.
- **CSV без потерь и предпросмотры (Linux, release):** восстановление тестовой копии через окно предпросмотра («добавится: 4», категория, бюджет, две операции), затем импорт выписки Т-Банка и экспорт CSV (UTF-8 с BOM, 11 колонок). После очистки данных этот CSV импортирован обратно через предпросмотр «Баланс, CSV» и экспортирован повторно: все поля, кроме «Изменено», совпали. «Изменено» отличается намеренно: импорт создаёт новую ревизию для синхронизации.
- **iOS и macOS не проверялись:** нужен Mac с Xcode. Эмулятор Android 37 с 16-КБ страницами на этой машине не загружается, проверка шла на образе API 35.

Ограничения:

- Реальных выписок банков нет: проверка только на синтетических фикстурах Т-Банка и OFX.
- Сбербанк напрямую не поддержан: используйте сопоставление колонок CSV или OFX.
- Восстановление не каскадирует переименования категорий в существующих операциях.
- Отчёт карантина содержит финансовые данные; храните и передавайте его осторожно.

## Быстрый ввод (4.2.0)

Автотесты: `test/quick_entry_test.dart` (7) — частые траты (два повтора за 90 дней, корректировки не учитываются, тип входит в шаблон), формат шаблонов, лимит 12 и отсутствие шаблонов в очереди синхронизации, строки виджета (баланс, траты месяца, остаток или превышение бюджета текущего месяца). `test/quick_entry_ui_test.dart` (18: 6 сценариев на 320×568, 390×844 и 1280×900) — «Повторить», «Сохранить как шаблон», чип и удаление долгим нажатием, частая трата, `initialAction` при запуске и входящее действие `income` по каналу `balance/launch`. Общий запуск: 124 теста PASS, анализатор No issues found.

Найдено и исправлено:
- Подсказка (`tooltip`) у чипа перехватывала долгое нажатие, и удалить шаблон было нельзя. Подсказка убрана, удаление работает долгим нажатием и правым кликом.
- `AppStore` ждал ответа платформенного канала `updateWidgets`. Без Activity (фоновый движок, тесты) ответ не приходил, и очередь операций хранилища останавливалась. Теперь обновление виджета запускается без ожидания.

Вручную на эмуляторе Android 15 (release x86_64): действие из уже открытого приложения (`onNewIntent`) и холодный запуск с действием открывают редактор с нужным типом. Ярлыки «Расход»/«Доход» зарегистрированы (`dumpsys shortcut`). Плитка Quick Settings открывает редактор расхода. Виджет добавлен через список виджетов лаунчера и показывает баланс, траты за месяц и превышение бюджета, совпадающие с приложением. «+» на виджете открывает редактор расхода, после сохранения виджет обновляется сразу. Тёмная тема виджета в порядке. Найдено и исправлено: в первой версии разметки суммы обрезались, теперь баланс уменьшает шрифт, а строки переносятся.

Не проверялось: ярлыки на iOS (нужен Mac). Виджета для iOS нет. Обновление виджета после фоновой синхронизации WorkManager видно только по его 30-минутному расписанию.
